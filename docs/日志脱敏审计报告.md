# 日志脱敏审计报告

- 审计时间：2026-09-17
- 审计范围：`backend/aichat/src/main/java`（Spring Boot 后端全部业务/控制器/服务/WebSocket 源码）
- 审计目标：排查日志输出是否泄漏密码、Token、API Key、Secret、验证码等敏感信息
- 审计方式：关键字正则扫描 + 人工复核命中行

---

## 一、检查范围与方法

### 1.1 扫描关键字
对 `logger.info / debug / warn / error / trace` 调用行做大小写不敏感扫描，关键字：

```
password | passwd | token | apiKey | api_key | secret | credential
```

并扩展排查：
- 直接打印整对象（`logger.xxx("...{}", user)`，因 User 用 Lombok `@Data`，`toString()` 会带出 password/mfaSecret/securityAnswer）；
- `System.out.println(...)` / `e.printStackTrace()`；
- `getApiKey()` / `getSecretKey()` / `getPassword()` / `getMfaSecret()` / `getSecurityAnswer()` 出现在日志参数中。

### 1.2 扫描结果概览
首轮正则命中 10 行，逐行人工复核后判定全部**已脱敏/仅输出标识**，无敏感明文泄漏。

### 2.1 既有防护机制确认
- **密码哈希**：`User.password` / `User.mfaSecret` / `User.securityAnswer` 均标注 `@JsonIgnore`，不进入 JSON 响应。
- **API Key 脱敏**：`AiSystemService#maskSecret(String)` 仅返回前 4 位，日志后缀 `***(masked)`；`secretKey` 全程不打印，仅记录 `systemId`。
- **重置令牌**：`UserServiceImpl` 历史 `System.out.println` 打印明文令牌的代码已在前序安全加固中移除，现仅输出前缀。
- **整对象打印**：未发现 `logger.xxx("{}", user)` 形式的整 User 对象输出（避免 Lombok `toString()` 带出 password/mfaSecret）。
- **System.out / printStackTrace**：主源码中无残留（仅存历史安全修复注释）。
