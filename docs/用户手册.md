# AI Chat 用户手册

> 面向普通用户 / 桌面端用户的操作指引。涵盖注册登录、角色对话、社交、广场、记忆、通知、桌面精灵、会员升级与管理员端概览。

---

## 1. 注册与登录

### 1.1 注册
1. 打开应用，进入「登录」页，点击「注册」。
2. 输入用户名、邮箱、密码（建议 8 位以上，含字母与数字）。
3. 点击「获取验证码」，输入邮箱收到的验证码。
4. 同意《用户协议》与《隐私政策》后点击「注册」。
5. 注册成功后自动登录，进入主页。

> 也可使用短信验证码登录（如管理员已开通短信通道）。

### 1.2 登录
- **账号密码登录**：输入用户名/邮箱 + 密码。
- **短信登录**：选择手机号登录，输入手机号 + 短信验证码。
- 忘记密码：登录页点击「忘记密码」，通过邮箱/短信验证码重置。

登录成功后系统会签发访问令牌（JWT），有效期约 24 小时；过期后需重新登录。

## 2. AI 角色：创建 / 对话 / 分享

### 2.1 创建角色
1. 左侧导航点击「创建角色」。
2. 填写角色名称、头像、简介、人设（System Prompt）、开场白。
3. 可选择绑定的大模型（豆包 / DeepSeek / OpenAI / 本地 Ollama）与音色。
4. 点击「保存」，角色出现在「我的角色」列表。

也可使用「角色生成器」用一句话描述自动生成人设，或通过「角色导入」从分享链接/文件导入他人分享的角色。

### 2.2 与角色对话
1. 在角色列表或聊天页选择角色，进入对话窗口。
2. 输入消息后回车发送；支持流式输出（逐字显示）。
3. 支持功能：
   - 多轮上下文记忆（自动携带历史）
   - 语音对话（STT 语音识别 + TTS 语音合成）
   - 图像生成（在对话中让角色画图）
   - 联网搜索（角色可调用搜索引擎获取实时信息）
4. 中途可「停止生成」。

### 2.3 分享角色
1. 在角色详情点击「分享」。
2. 生成分享链接，发给好友；对方打开链接即可「试用」或「导入」到自己的角色库。

## 3. 好友 / 群聊 / 社群

### 3.1 好友
- 添加好友：通过搜索用户 / 扫码 / 分享链接发送好友请求，对方同意后成为好友。
- 好友私聊：在「好友」页选择好友，进入一对一聊天窗口。

### 3.2 群聊
- 创建群聊：选择多名好友建群，设置群名称与头像。
- 群内可拉 AI 角色进群：@AI 角色即可让其发言，多人与 AI 同群互动。

### 3.3 社群 / 社区
- 「社群」页浏览他人发布的角色讨论、动态帖子，可点赞、评论、关注作者。
- 发布自己的帖子分享角色使用心得。

---

## 4. 广场 / 记忆 / 通知

### 4.1 角色广场
- 「广场」页匿名/登录均可浏览热门角色、官方推荐角色。
- 按分类、标签、排序筛选；点击卡片查看角色详情并「立即使用」。

### 4.2 AI 记忆
- 「记忆」页查看 AI 角色记住的关于你的长期记忆片段。
- 可查看、编辑、删除单条记忆；清除记忆后 AI 将不再引用该信息。

### 4.3 通知
- 「通知」页集中查看：好友请求、群聊邀请、系统公告、互动回复、会员到期提醒等。
- 未读消息有红点提示。

## 5. 桌面精灵

1. 进入「桌面精灵」（AiElf）页，选择一个拟人形象。
2. 开启后屏幕角落会悬浮一个可拖动的小精灵，随时点击唤起对话。
3. 可切换形象、调整大小、设置开机自启（桌面端 / Electron 版本）。
4. 支持手势交互（基于 MediaPipe 手势识别，桌面端可用）。

> 桌面精灵为客户端功能，纯网页版不可用悬浮桌面窗口。

## 6. 个人中心与会员升级

### 6.1 个人中心
- 「我的」页查看/编辑头像、昵称、个性签名。
- 查看账号资料、隐私设置（「隐私」页可管理数据捕获规则、注销账号）。

### 6.2 会员与升级
- 「升级」/「会员」页查看当前套餐与额度（对话次数、图像生成次数等）。
- 不同套餐对应不同的模型权限与调用配额，按需升级。
- 额度用尽时会引导充值/升级。

## 7. 管理员端功能概览

管理员使用专用账号登录后，进入「管理后台」，主要功能包括：

| 模块 | 说明 |
| --- | --- |
| 用户管理 | 查看/封禁/解封用户，调整用户角色与配额 |
| 公告管理 | 发布、编辑、上下线系统公告 |
| 内容审核 | 审核用户生成内容、帖子，处理举报（拉黑/举报） |
| 角色管理 | 审核上架到广场的角色，下架违规角色 |
| 数据池管理 | 管理 AI 训练/数据池，密钥加密存储 |
| 数据备份 | 触发/查看数据库备份，管理备份策略 |
| 广告管理 | 管理首页/广场广告位 |
| 支付/账户 | 管理会员套餐、支付账户配置、订单审核 |

> 普通用户无法访问 `/api/admin/**` 接口，前端也不展示管理入口。

## 8. 常见问题（FAQ）

**Q1：登录后很快又要求重新登录？**
A：访问令牌有效期约 24 小时，属正常过期。如频繁掉线，检查设备系统时间是否正确。

**Q2：发消息一直转圈、没有回复？**
A：可能是后端模型服务（Ollama / 云端 API）不可用或网络超时。先确认网络，或在设置中切换到其他可用模型。

**Q3：语音功能没声音？**
A：检查浏览器/系统麦克风权限；语音合成提供者需在后台配置（默认免费 Google 翻译 TTS，识别用 Whisper 需 Key）。

**Q4：生成的图片不显示？**
A：图像生成依赖 SD WebUI 或 OpenAI DALL·E，确认 `IMAGE_PROVIDER` 与服务可用；图片经 `/uploads/` 访问，需网络可达。

**Q5：桌面精灵不显示？**
A：桌面精灵仅在 Electron 桌面端可用；纯网页端不支持系统级悬浮窗。

**Q6：好友消息收不到？**
A：好友/群聊走 WebSocket，确认网络稳定、页面未长时间休眠；必要时刷新页面。

**Q7：如何删除我的数据 / 注销？**
A：个人中心 →「隐私」页可管理数据捕获规则并申请注销账号。

**Q8：额度用完怎么办？**
A：「升级」页提升套餐或等待次日额度重置（具体以套餐规则为准）。
