| 课题意义、主要研究内容/设计目标 | 1.课题意义<br><br>1.课题意义：本课题针对通用聊天机器人缺乏人格化设定、记忆连续性不足、依赖云端服务存在隐私与成本问题等现状，设计并实现一个基于本地大模型的智能AI陪伴聊天系统。系统通过AI角色与AI精灵双体系提供个性化陪伴，基于“记忆—经历—感受—自我”的灵魂算法构建长期记忆机制，实现“越聊越懂你”的持续陪伴体验；采用Ollama本地化部署保障用户数据隐私、降低使用成本；支持Web端、桌面端与移动端多端使用，并融合好友、群聊、兴趣社群等社交功能。创新点包括：基于Ollama的开源大模型私有化部署方案、融合向量检索与时间衰减的AI记忆机制、AI桌面宠物互动以及三端统一架构。<br><br>2.主要研究内容<br>2.主要研究内容：（1）系统总体架构设计：前后端分离架构，Spring Boot 3.2.5、Vue 3、MySQL 8与Redis，支持Web端、Electron桌面端与移动端三端复用；（2）AI角色引擎：角色创建、人设提示词、上下文管理与角色一致性对话；（3）AI记忆系统：基于向量检索、重要度评分与时间衰减的长期记忆机制；（4）AI精灵与桌面宠物：形象更换、互动反馈与语音对话；（5）社交模块：好友、私聊、群聊、兴趣社群与动态发布；（6）语音交互：语音识别与语音合成；（7）管理员后台：用户管理、数据池管理、公告管理与AI系统管理；（8）安全合规：JWT认证、RBAC权限控制、内容审核与未成年保护；（9）测试体系：单元测试、集成测试与系统测试。<br><br>3.主要设计目标<br>3.主要设计目标：实现功能完整、安全健壮、流畅运行的智能AI陪伴聊天系统，覆盖Web端、桌面端与移动端三端；完成自动化测试用例1000个以上并全部通过，系统全链路稳定运行；交付符合福州理工学院毕业设计规范的设计文档、源代码与毕业论文。<br> |  |  |  |  |  |  |  |  |  |  |  |  |
