## 1. Bug报告模板

### 1.1 报告格式

| 字段 | 说明 | 示例 |
|-----|------|------|
| Bug编号 | 唯一标识 | BUG-001 |
| 严重程度 | 严重/高/中/低 | 高 |
| 模块 | 问题所属模块 | 桌面精灵 |
| 标题 | 简洁描述问题 | 桌面精灵面板被屏幕边缘遮挡 |
| 复现步骤 | 详细的复现步骤 | 1. 登录系统<br>2. 将桌面精灵拖动到屏幕右下角<br>3. 点击打开面板 |
| 错误表现 | 问题的具体表现 | 面板右侧和底部被屏幕边缘遮挡，部分内容不可见 |
| 环境信息 | 操作系统、浏览器等 | Windows 10, Chrome 120 |
| 发生频率 | 总是/经常/偶尔/罕见 | 总是 |
| 预期结果 | 期望的正确行为 | 面板自动调整位置，完整显示在屏幕内 |
| 实际结果 | 当前的错误行为 | 面板被屏幕边缘遮挡 |
| 状态 | 待修复/修复中/已修复/已验证 | 已修复 |
| 修复版本 | 修复该bug的版本号 | v1.0.1 |
| 修复描述 | 修复的具体内容 | 修改了面板位置计算逻辑，增加边界检测 |

### 1.2 严重程度定义

| 等级 | 定义 | 示例 |
|-----|------|------|
| 严重 | 导致系统崩溃、数据丢失或核心功能完全不可用 | 登录功能失效、聊天消息发送失败 |
| 高 | 核心功能部分失效，影响用户正常使用 | 桌面精灵面板遮挡、闹钟不触发提醒 |
| 中 | 非核心功能异常，用户体验受影响 | 界面布局错位、按钮样式异常 |
| 低 | 轻微问题，不影响功能使用 | 文字拼写错误、图标显示不清晰 |
