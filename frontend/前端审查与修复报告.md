## 三、每项修复内容与证据

### 修复 1（P1）：管理员头像上传改走可用端点
- 文件：`src/views/AdminProfileView.vue`
- 改动：`POST /api/admin/upload-avatar` → `POST /api/user/upload-avatar`（UserController:368 已存在，管理员 token 指向自身 User 记录）；返回字段由 `response.data.avatarUrl` 改为 `response.data.filePath || response.data.avatarUrl`，与普通用户 ProfileView 一致。
- 证据：该端点实际保存图片并返回 `filePath`；localStorage 用户头像同步更新。

### 修复 2（P1）：管理员资料拉取改走可用端点
- 文件：`src/views/AdminProfileView.vue`
- 改动：`GET /api/admin/profile` → `GET /api/user/me`（UserController:227，`@PreAuthorize("isAuthenticated()")`，管理员 token 可访问，返回当前 User）。
- 证据：页面先从 localStorage 填充，再用服务端最新数据 `Object.assign` 覆盖，登录后资料可与服务端同步；失败仍静默兜底不白屏。

### 修复 3（P2）：接入"今日剩余"额度显示
- 文件：`src/views/ChatView.vue`
- 改动：引入 `getCurrentQuota`；新增 `quotaText` 与 `loadQuota()`（try/catch 包裹，失败不阻塞聊天）；`onMounted` 调用；侧边栏在操作按钮上方渲染 `今日剩余 AI 对话 X / Y 次`，`limit<=0` 显示"AI 对话：不限次"，`available===false` 不渲染；附 `.quota-info` 样式。
- 证据：对齐后端 `QuotaServiceImpl.getCurrentQuota` 返回结构 `data.features.ai_chat.{used,limit,remaining,available}`。

### 修复 4：补单元测试
- 新增 `tests/unit/quota.test.js`（4 例）：mock `@/utils/request`，锁定 `getCurrentQuota→GET /api/quota/current`、`deleteChatSession→DELETE /api/chat/session/{id}`、`deleteChatMessage→DELETE /api/chat/message/{id}`、`exportMyData→GET /api/user/data/export` 的方法与 URL 契约。
